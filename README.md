# Health Organizer 

This repository contains the project for the **CS 4800 Software Engineering, Full Stack**.  

### **Project Overview** 
**Health Organizer** is a Web Application designed to help users organize and keep track of their health information in one place by allowing users to maintain organized health records and easily review their information over time.

---

### Core Features  
- **Medication Tracking** — assign and complete household tasks  
- **Appointment Logs** — Upload an image of a receipt to get the total and divide it between roommates for tracking shared expenses 
- **Symptom Tracking** — manage events and reminders  
-  *Stretch Features:* shared grocery list, guest tracker, and notifications  


---

## Technologies Used 

- **Frontend:** HTML, CSS, JavaScript   
- **Backend:** Python, Flask
- **Database:** MongoDB 
- **Deployment:** AWS EC2

---

## Getting Started  

### Prerequisites  
- Node.js 20+  
- Git + GitHub account  

### Setup  
```bash
# Clone the repository
git clone https://github.com/CPP-SheCodes-SLP-2025-26/fullstack.git
cd fullstack

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Run the application locally
npm run dev

```
