# Health Organizer 

This repository contains the project for the **CS 4800 Software Engineering, Full Stack**.  

### **Project Overview** 
**Health Organizer** is a Web Application designed to help users manage and keep track of their health information in one place. It allows users to maintain organized health records and easily review their information over time.

---

### Core Features  
- **Medication Tracking** — Add medication names, dosages, and weekly or daily reminders 
- **Appointment Logs** — Keep track of doctor visits by medical specialty, date, appointment status, and reason for the visit
- **Symptom Tracking** — Document symptoms with the date, pain level, and additional notes
-  *Stretch Features:* Doctor profiles and cycle tracker


---

## Technologies Used 

- **Frontend:** HTML, CSS, JavaScript   
- **Backend:** Python, Flask
- **Database:** MongoDB 
- **Deployment:** AWS EC2
